# DatoYa 2.0 — siguiente etapa

Este archivo documenta el alcance de la siguiente iteración. Mantener pagos en modo DEMO hasta integrar un PSP real y completar revisión legal.

## Objetivos
- GPS de viaje: inicio, actualizaciones, llegada y detención automática.
- Cliente: estado "El profesional va en camino", última actualización y ubicación aproximada.
- Evidencias: ANTES / PROCESO / DESPUÉS, revisión del cliente y trazabilidad.
- Disputas: problema, corrección, resolución y auditoría.
- Producción posterior: almacenamiento firmado, antivirus, mapas/PSP reales, PostgreSQL, HTTPS, privacidad y legal.
